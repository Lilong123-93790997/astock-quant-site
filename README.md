# A股量化研究工作站 · A-Share Quant Research Workbench

一个“多市场实时数据 + 因子研究 + 专业回测 + AI 诊股 + 职业交易计划书”的桌面量化研究工作站（A股 / 港股 / 美股）。

A Windows desktop quant research workbench covering A-shares, HK and US markets: live data, factor lab, professional backtesting, AI diagnosis and a professional trade-plan generator.

---

## 功能特性 Features
- 实时行情：多源接入（腾讯/东财/新浪），**默认仅实时**；收盘显示最近一笔真实价并标注；绝不拿模拟数据冒充实时。
- 全市场：全A股 + 港股 + 美股（断网用内置名单兜底，只补名称不带假价）。
- 研究实验室：Alpha101/Alpha158 因子、IC/RankIC 体检、遗传规划自动挖因子。
- 专业回测：多策略模板、参数寻优、Walk-Forward 样本外验证、交易成本/滑点/止损。
- 自然语言生成策略：一句话描述 → 自动变可回测策略（可选大模型结构化）。
- 组合诊断驾驶舱：多基准归因、RBSA 风格暴露、MCTR/CVaR 风险分解、持仓效率象限。
- 职业交易计划书：市场状态 → 技术快照 → 头寸计算 → 实盘合规预检 → 情景计划。
- 盘前作战简报 / 每日复盘：自动生成并推送（Bark / Server酱 / 企业微信）。
- 程序内可视化弹窗：所有研究结果直接弹窗看图看表，无需去文件夹找文件。
- 授权体系：商家授权服务器（HTTP/HTTPS）＋客户版激活码，支持试用/到期管理。
